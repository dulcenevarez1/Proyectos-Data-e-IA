# Proyectos-Data-e-IA
Descripción
Este proyecto tiene como objetivo analizar las ventas de AdventureWorks 2022 utilizando Power BI, proporcionando insights clave a través de KPI y visualizaciones interactivas.

Estructura del Proyecto
/data/ → Contiene los archivos de la base de datos (si aplica).
/dashboard/ → Archivo .pbix con el dashboard en Power BI.
/docs/ → Documentación adicional o reportes exportados.
README.md → Este archivo con la descripción del proyecto.

 Objetivos del Proyecto
Monitorear el desempeño de las ventas mediante KPI clave.
Analizar tendencias y patrones en los ingresos.
Identificar clientes más valiosos y productos más vendidos.
Evaluar la tasa de devoluciones para mejorar la calidad de las ventas.

KPIs Implementados
Ingresos Totales → Evolución de ventas en el tiempo.
Cantidad de Pedidos Realizados → Actividad comercial por periodo.
Ticket Promedio por Venta → Gasto promedio de clientes por transacción.
Top 5 Clientes por Ingresos → Clientes más rentables.
Tasa de Devoluciones → Control de calidad y satisfacción del cliente.

Visualizaciones Utilizadas
Tarjetas KPI
Gráficos de líneas
Gráficos de barras
Gráficos de anillos
Segmentaciones de datos

Tecnologías y Herramientas
Power BI
SQL Server (para consultas sobre AdventureWorks)
DAX (para medidas y cálculos)
